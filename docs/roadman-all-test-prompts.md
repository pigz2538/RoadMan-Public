## 8. 执行顺序和自动化命令

### 8.1 预检

预检只验证需求理解、结构化日期、起终点、人数、交通偏好和必达点，不落库、不制造假行程：

    python evaluation/run_evals.py --scenarios evaluation/scenarios.json --output evaluation/results/scenarios-latest.json
    python deploy/weird_prompt_acceptance.py --scenarios evaluation/weird_live_scenarios_v3.json --full-limit 0 --output evaluation/results/weird-live-v3-preflight-latest.json

### 8.2 完整规划验收

完整验收必须等待“新建 → 工具调用 → 规划完成 → 校验 → 导出”：

    python deploy/weird_prompt_acceptance.py --scenarios evaluation/weird_live_scenarios_v3.json --full-limit 7 --output evaluation/results/weird-live-v3-full-latest.json
    python deploy/edit_replan_acceptance.py --start-index 1 --end-index 10

E 组的每一条都要确认：修改预览出现后才开始动画；确认后只启动一次重排；地图、左侧全天安排、阶段卡、酒店/餐饮/景点卡和导出快照来自同一版本。

### 8.3 运行环境和降级

    docker compose up -d --build
    docker compose ps
    python -m pytest backend/tests -q

可模拟天气、地图、交通、补能或检索服务不可用，但必须在结果中标出降级来源，不能把缓存或 Mock 结果伪装成实时事实。真实凭证只从本地环境读取，禁止写入本文、截图或提交记录。
