## 自驾深度规划节点

阶段 E 在原 LangGraph 中新增：

1. `load_vehicle_profile`：优先读取 Trip 选择的车辆；缺失时使用带
   `estimated=true` 的纯电 SUV 样本。
2. `discover_services`：按驾车路线中点查询服务区、充电、加油、停车、餐饮、
   医院和公共厕所；往返同走廊单次查询失败时只复用 60 km 内已确认 POI。
3. `enrich_deep_drive`：估算逐段能耗与剩余电量/油量，应用安全余量、山路、
   车高、连续驾驶、午餐和夜间约束。
4. Weather Risk：使用每个阶段预计到达时刻的逐时温度、降水、能见度和风速，
   写入 `risk_level`、`risk_tags` 与可追溯 Warning。
5. Verification：校验续航、必要补能、连续驾驶、逐时天气和数据缺失；必要补能
   或休息无法安排时阻断完成，非关键第三方数据失败则降级为 Warning。

## 调度规则

- 默认安全能量余量为 15%，Vehicle 可配置 5%–40%。
- 驾车时间超过 `max_continuous_drive_minutes` 时插入休息。
- 同一路段同时需要补能和休息时合并为一次停靠。
- 阶段跨越 11:30–13:00 时尝试插入沿途午餐。
- 纯电按电池容量与百公里电耗估算，燃油/混动按额定续航与油耗估算。
- 山地目的地使用 1.12 能耗系数；所有推算结果均标记为估算。
- 高德路况是当前参考，不伪装成未来拥堵预测。

## API 与页面

- `GET /api/v1/trips/{trip_id}/risks`：阶段风险摘要、标签和警告。
- `GET /api/v1/trips/{trip_id}/services`：七类候选沿途服务及已选停靠。
- 阶段卡显示风险标签、能耗与估算警告。
- 中高风险路线在高德地图使用橙色道路轨迹。
- “风险与自驾校验”详情展示分阶段风险、来源含义和估算标记。
- 地图 POI 长名称限制宽度，相邻点位中较大的行程序号置于上层。
