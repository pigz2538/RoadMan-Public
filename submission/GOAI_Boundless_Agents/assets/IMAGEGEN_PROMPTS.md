# 生成式视觉说明

方案书中的 `roadman-cover-hero.png` 与 `multi-agent-hero.png` 使用 Codex 内置图像生成工具生成，未使用第三方品牌标识、人物肖像或受保护角色。精确中文架构图由 `tools/diagrams.html` 与 `tools/render_diagrams.mjs` 代码生成。

## 封面主视觉

使用模式：内置图像生成工具（默认模式）。

提示词摘要：为 RoadMan 智能自驾旅行规划系统生成无文字、超宽横向的高级编辑型 3D 插画；白色电动 SUV 沿蓝色路线行驶，周围抽象节点表示地图、天气、补能、住宿、餐饮、景点与安全；冰蓝/白背景，左上留出标题空间；禁止文字、Logo、水印、人物和品牌标记。

## 多智能体协作主视觉

使用模式：内置图像生成工具（默认模式）。

提示词摘要：以中央规划核心和六个能力模块表现需求理解、目的地研究、路线计算、日程编排、每日复核和结果交付的协作回路；电动车路线从输入进入系统并输出已验证行程；白色与浅蓝背景、企业级 3D 信息图风格；禁止文字、Logo、水印、机器人角色和品牌标记。
